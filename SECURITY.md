# Security Policy

## Supported Versions

Currently, only the latest version of `mcpanel` receives support and security patches.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x: |

## Reporting Vulnerabilities

If you discover a security vulnerability in the `mcpanel` project, please report it to us privately. **Do not report security issues publicly** in the *Issues* tab.

You can choose from two reporting methods:
1. **GitHub Security Advisories:** Go to the **Security** tab in the repository and click **Report a vulnerability**.
2. **E-mail:** Send a message directly to: `cyberresistor@proton.me`.

Please include the following in your report:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue (Proof of Concept).
- Environment information (Python version, `mcpanel` version).

Thank you for helping keep the project secure!

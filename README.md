# MCPanel
An all-in-one library providing server interfaces and tools to assist Minecraft server developers.

I created this library because I was annoyed at having to visit websites for plugins or server engines ;)

examples are in docs

### Installation 
its very simple here examples:
#### uv
```bash
uv pip install mcpanel
```
#### normal pip
```bash
pip install mcpanel
```
